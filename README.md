# 영어 세특 자동 생성 프로그램

Google Sheets의 학생 영작과 교사 입력 점수를 바탕으로 영어 교과 세특 초안을 작성하는 Apps Script입니다. 현재 과제는 **시민과학과 연계한 나의 연구 계획서 작성하기**입니다.

## 현재 버전

- 기본 생성: Gemini 3.8 Flash (`gemini-3.8-flash`)
- 교사가 선택한 학생만 재작성: GPT-6 Sol (`gpt-6-sol`)
- 두 모델에 같은 첫 문장·전개·종결 규칙과 원문 근거 검증 적용
- 전체 결과 1,500바이트 상한, 완결된 문장 단위 축약
- 입력 값·수식 보존, 학생 자료 시트 U·V에만 결과 기록
- Sol 재작성 전후 결과 기록, 중단한 시트·행·모델을 유지해 재개

## 설치와 사용

1. 학생 자료 스프레드시트에서 **확장 프로그램 → Apps Script**를 엽니다.
2. 기존 세특 코드 전체를 [Code.gs](Code.gs)의 내용으로 교체합니다. 기존 코드 뒤에 추가하지 않습니다.
3. 저장하고 스프레드시트를 새로고침합니다.
4. **📝 영작 세특 생성 → ⚙️ API / 모델 / 선택 점수 열 설정**에서 Gemini API 키를 저장합니다.
5. 학생 행을 선택하고 **① 선택한 행 Gemini 3.8 생성**을 실행합니다. 범위 입력은 ② 메뉴를 사용합니다.
6. 먼저 몇 명의 원문과 결과를 대조한 뒤 범위를 늘립니다.

우수 학생은 교사가 직접 선택합니다. 나중에 OpenAI API 키를 추가하고 원하는 행을 선택해 **④ 선택한 행만 Sol로 다시 작성**을 실행합니다. Ctrl로 떨어진 셀·범위를 선택할 수도 있습니다. 이후 기본 메뉴는 계속 Gemini 3.8을 사용합니다.

자세한 기입 규칙·백업·재개 방법은 [사용 안내](사용안내.txt)를 참고하세요.

## 열 배치

| 열 | 내용 |
| --- | --- |
| M | 기존 말하기·듣기 세특 |
| N | 참고 바이트 |
| O | 학생 영작 원문 |
| P | 공식 단어 수 |
| Q | 목표 언어 점수: 1, 2, 3 |
| R | 문법·표기 점수: 1, 1.5, 2 |
| S | 문장 수 |
| T | 기입 수준 |
| U | 통합 세특 |
| V | 통합 바이트 |

내용 평가 5개 항목의 점수 열은 선택 설정입니다. 아직 별도 열이 없다면 비워 둡니다. T의 부정행위·미제출은 결과를 강제로 비우고, 참가함은 고정 참가 문장만 기록합니다. 일반적인 원문 빈칸과 API·검증 실패는 기존 결과를 유지합니다.

## 원문 근거와 비용

주제와 문장마다 원문 인용을 받아 코드가 인용의 존재를 확인하고, 별도 AI 요청으로 의미를 검증합니다. 계획을 실제 수행·성과로 바꾸거나 원문에 없는 구문·도구·경험을 추가하면 반려하도록 했습니다. 단어 수를 간접 평가 지표로 쓰되 근거가 적으면 짧게 끝낼 수 있습니다.

정상 AI 생성은 작성 1회와 검증 1회, 보통 학생당 총 2회의 API 요청입니다. 보정은 최대 1회이며 재검증까지 총 4회까지 요청합니다. HTTP 오류 재시도는 별도입니다. AI 검증에도 해석 오류가 남을 수 있어 최종 기재 전 원문 대조가 필요합니다.

API 키는 스프레드시트 문서 속성에 저장합니다. 소스나 저장소에 키와 실제 학생 자료를 넣지 않습니다. Codex/ChatGPT 구독과 OpenAI API 비용은 별개이며 Gemini와 OpenAI의 결제 계정도 따로 관리합니다.
