# 📝 영어 영작 세특 자동 생성 프로그램 (AI Convergence Project)

> **학생들의 "나의 기업 투자 제안서" 영작 수행평가 데이터를 바탕으로, 생기부 기재 요령과 제한된 바이트 수에 맞춘 완벽한 세특(세부능력 및 특기사항)을 자동으로 생성해 주는 Google Sheets 기반 AI 스크립트입니다.**

## 1. 💡 기획 배경 및 목적
* 한정된 기한 내에 수백 명의 학생 세특을 개별화하여 작성해야 하는 교사의 막중한 행정 및 평가 부담을 획기적으로 줄이기 위해 개발되었습니다.
* 특히 단순한 텍스트 생성을 넘어, **생기부 기재 지침(부정적 서술 금지, 정해진 종결어미, 근거 기반 서술)**을 AI 프롬프트에 엄격하게 적용하여 즉시 나이스(NEIS)에 입력할 수 있는 수준의 결과물을 도출합니다.
* 학생이 기존에 취득한 '말하기/듣기/어휘' 세특 바이트 수를 스스로 계산하여 남은 여백(최대 1500바이트)에 딱 맞게 영작 세특을 맞춤 생성합니다.

## 2. ✨ 주요 기능 (Features)
* **멀티 LLM 완벽 지원 (Multi-Provider):** Gemini(Google), ChatGPT(OpenAI), Claude(Anthropic) 모델을 모두 지원하며, 시트 내 UI 메뉴에서 API 키와 모델을 클릭 한 번으로 손쉽게 전환할 수 있습니다.
* **스마트 바이트 계산 및 자동 컷팅:** 한글 1자당 바이트 수를 계산하여 전체 1500바이트 한도를 절대 넘지 않도록 통제합니다. 분량 초과 시 문장 중간이 아닌 마침표(`.`)를 기준으로 깔끔하게 텍스트를 절삭(Smart Cutting)하는 안전장치를 갖추었습니다.
* **단어 수 기반 성취 수준 차등화 (Word Tiering):** 학생이 영작에 사용한 단어 수를 5단계(300단어 이상 최극상 ~ 100단어 미만 기본미달)로 자동 분류합니다. 상위권 학생에게는 분석의 깊이와 분량을 대폭 늘리고, 하위권 학생에게는 과장 없이 담백한 팩트 위주로 서술 비중을 자동 조절합니다.
* **엄격한 평가 지침 강제 (Strict Prompting):** 
  * "아쉽다", "부족하다" 등의 부정적 단어를 프롬프트 단에서 원천 차단합니다.
  * "~함", "~임" 등의 개조식(음슴체) 종결어미를 강제합니다.
  * 미제출자나 부정행위자는 자동으로 필터링하여 빈칸 처리합니다.

## 3. 🛠 사용 기술 (Tech Stack)
* **Language:** JavaScript (Google Apps Script)
* **Environment:** Google Sheets, Google Workspace
* **Integration APIs:** 
  * Google Gemini API (`gemini-3.5-flash`, `gemini-3.1-pro-preview` 등)
  * OpenAI API (`gpt-4o` 등)
  * Anthropic API (`claude-3-5-sonnet` 등)

## 4. 🚀 사용 방법 (How to Use)
1. **스크립트 적용:** 학생 평가 데이터(M열~T열)가 있는 구글 시트에서 `[확장 프로그램] > [Apps Script]`를 열고 이 코드를 덮어쓴 후 저장합니다.
2. **권한 및 설정:** 시트를 새로고침하면 상단에 **`📝 영작 세특 생성`** 메뉴가 나타납니다. 
3. **API 설정:** 메뉴의 `[⚙️ 설정 (API 키 / 모델)]`에 들어가 사용할 AI 서비스의 API 키를 입력하고 모델을 선택합니다.
4. **실행:** 세특을 생성할 학생의 행(Row)을 드래그하여 선택한 뒤, 메뉴에서 `[① 선택한 범위로 세특 생성 (초고속)]`을 클릭합니다.
5. **결과 확인:** U열에 기존 세특과 결합된 최종 세특 텍스트가, V열에 최종 바이트 수가 자동으로 산출됩니다.

## 5. 👨‍💻 기대 효과
* 학생 개개인의 영어 단어 수, 문법 점수, 작문 원문 데이터를 종합적으로 분석하므로 **'복붙' 느낌이 없는 100% 개인화된 고품질 세특**을 보장합니다.
* 교사의 세특 작성 및 검토 시간을 기존 대비 80% 이상 단축하여, 교사가 본연의 교육 및 학생 지도에 집중할 수 있는 환경을 제공합니다.
* 바이트 수 초과로 인해 나이스(NEIS) 입력 시 발생하는 텍스트 짤림 오류를 사전에 완벽히 방지합니다.
